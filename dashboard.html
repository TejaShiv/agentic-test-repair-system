How the agent works ▸
  1. Run the tests. Execute the target project's suite and capture which tests fail and why.
  2. Read the code. Load the source file the failing test exercises.
  3. Ask for a repair. Send the failing test output and the source to the model, constrained to return only corrected code.
  4. Apply and verify. Write the fix back and re-run the tests to check whether they now pass.
  5. Loop or stop. If still failing, feed the new error back and retry up to a set limit; otherwise report success.
